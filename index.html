📍 Lokasi tidak akurat / gagal diambil? Ketuk untuk solusi

Akurasi ideal ±5–30 m. Kalau tampil ratusan/ribuan meter (mis. ±2000 m), HP memakai lokasi jaringan WiFi/sinyal — bukan GPS satelit. Perbaiki begini:

  1. Nyalakan Lokasi/GPS — geser layar dari atas ke bawah, ketuk ikon Lokasi sampai menyala.
  2. Pakai Akurasi Tinggi — Setelan → Lokasi → Layanan Lokasi / Akurasi Lokasi Google → Aktif. Jangan mode "Hemat baterai" (itu mematikan GPS).
  3. Izin lokasi browser = "Tepat" — Setelan → Aplikasi → Chrome → Izin → Lokasi → pilih "Tepat/Precise" + "Izinkan saat digunakan". (Kalau "Perkiraan/Approximate", akurasi sengaja dikaburkan.)
  4. Keluar ruangan / dekat jendela — hindari gedung beton, basement, atau di dalam mobil tertutup.
  5. Ketuk Ambil Lokasi lagi dan tunggu 10–20 detik sampai angka akurasi mengecil — jangan buru-buru mengirim saat masih ratusan meter.

✅ Contoh berhasil: muncul tulisan hijau "Lokasi terekam (±12 m)". Kalau kuning "Akurasi rendah", ulangi langkah 2–5 di tempat terbuka.
